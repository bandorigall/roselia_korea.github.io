================================================================
로젤내한 (Roselia 내한대비 곡 리스트) — 모듈 개요 (기술 명세)
================================================================

0. 목적
  Roselia 내한 공연 대비, 셋리스트 후보곡을 "과거 기반 선곡률"·투어 실연
  여부와 함께 정리하고, 곡별 콜(응원) 표시가 들어간 가사·콜가이드 영상을
  제공한다. 배포: GitHub Pages 정적 페이지.

1. 저장소 구성
  roselia.csv          입력 데이터(단일 소스). UTF-8.
  convert.ipynb        빌드 노트북(CSV → index.html). JSON 인라인 주입.
  index.html           빌드 산출물(정적).
  roselia_songs.html   구/보조 버전 페이지.
  roselia_logo.webp    헤더 로고.

2. CSV 스키마 (roselia.csv)
    제목(원어)            곡명(원어)
    제목(한국어)          한국어 제목(없으면 공백)
    발매일                YYYY-MM-DD
    과거기반 선곡률        과거 공연 통계상 선곡 확률(정수 %)
    투어_오사카            해당 투어 실연 여부 플래그
    투어_싱가폴            해당 투어 실연 여부 플래그
    유튜브                공식/음원 영상 URL
    가사(콜표)            콜 표시가 포함된 가사 HTML(색/하이라이트 마크업 포함)
    가사(콜표) 2          가사 이어붙임용 2번째 컬럼
    콜가이드영상          콜 가이드 영상 URL

3. 빌드 파이프라인 (convert.ipynb: generate_html)
  - csv.DictReader로 로드. '제목(원어)'가 있는 행만 채택.
  - 가사(콜표) + 가사(콜표) 2 를 이어붙여 단일 가사 필드로 병합
    (긴 가사 HTML을 CSV 셀 한도/편집 편의상 두 컬럼으로 나눠 저장한 것을 재결합).
  - json.dumps(songs, ensure_ascii=False)를 HTML 템플릿에 인라인 주입.
  - Roselia 테마(다크 퍼플 #1A0B2E, 헤더 그라디언트 #4a148c→#6a1b9a).

4. 프런트엔드 동작 (index.html)
  - 곡 리스트: 선곡률/투어 실연 여부 표시. 곡 선택 시 가사(콜표) 모달/패널로
    콜 하이라이트가 포함된 가사와 콜가이드 영상 링크 노출.
  - 가사 HTML은 CSV에 저장된 마크업(색상 font/배경 span)을 그대로 렌더.

5. 설계 결정/제약
  - 콜 표시는 가사 HTML 안에 색/배경 마크업으로 직접 인코딩(빨강=콜 등).
  - 가사 컬럼을 2개로 분리 저장 후 빌드 시 병합(대용량 셀 취급).
  - 빌드가 노트북(.ipynb)이라 수동 실행형. 데이터 갱신 = CSV 편집 후 재실행.
  - (주의) convert.ipynb 소스 문자열 일부가 cp949로 저장돼 한글이 깨져 보일 수
    있으나 실행에는 무관(파일 입출력은 encoding='utf-8' 지정).
